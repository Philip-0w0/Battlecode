Performance and release decision:
Five pre-final comparison games against the frozen Python bot won 1/5. The final
source also lost Monolith B (708-1008). These are separate source checkpoints,
not a claim of one identical-source six-game suite. The current port performs
worse than Python, so Python remains the recommended default. The C++ port is
an available migration candidate, not an automatic strategy improvement.
Native fuel overruns remain a tuning priority. A lower-reserve variant lost both
Packs screens and logged an error, so that variant was rejected.

Runtime differences handled during migration:
- Native ordinary fuel is approximately 100,000 versus 2,500,000 for Python on
  engine 2.0.0. Reserve thresholds were scaled; literal Python totals caused the
  first prototype to yield without acting and were not released.
- Stable roster and camp metadata are reused; live health/position queries stay
  fresh. Enemy Heart ability metadata is explicitly rebound once visible because
  C++ ability views cache their construction-time visibility result.
- Python min/max first-tie behavior and group-score/index tie rules are preserved.
- C++ standard exceptions are logged and yield a turn; Python traceback formatting
  is language-specific and is not reproduced as a fake native stack trace.
